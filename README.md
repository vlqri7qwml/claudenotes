# ClaudeNotes

基于思源笔记 v3.8.6 源码修改的本地笔记软件：claude.ai 风格界面，原生支持粘贴和导入 AI 对话，笔记、配置、缓存全部放在安装目录，思源官方云端服务默认关闭（可一键开启）。可以与官方思源同时安装、互不影响。

| 文档 | 内容 |
| --- | --- |
| [CLAUDENOTES.md](CLAUDENOTES.md) | 与官方思源的区别、数据目录、存储格式、AI 对话功能、构建、发布、许可 |
| [TESTING.md](TESTING.md) | 手动测试清单 |
| [CLAUDE.md](CLAUDE.md) | 给 AI 助手（新对话）看的代码索引、当前状态和协作规则 |
| [docs/SIYUAN-README.zh-CN.md](docs/SIYUAN-README.zh-CN.md) | 思源笔记官方原始说明（参考） |

安装包在本仓库的 Releases 中下载（由 `.github/workflows/claudenotes.yml` 构建）。

许可：AGPL-3.0（沿用思源笔记），详见 [LICENSE](LICENSE) 与 CLAUDENOTES.md 的「许可」一节。
